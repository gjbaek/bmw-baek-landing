## 디자인과 영상

흰색 상단 바와 개인 이름 중심의 표기를 적용했습니다. 큰 차량 배너와 어두운 인물 소개 영역은 유지합니다. Pretendard 본문 400·500, 소제목·버튼 600, 핵심 제목 800으로 강약을 구분합니다.

담당자 호칭은 백경재 대리로 통일했습니다. 주요 제목·본문·보조 문구의 크기를 통일하고, 대표 차량 카드의 높이와 버튼 위치를 맞췄습니다. 차종 카드 4개 중 하나를 누르면 아래 공통 영역에 해당 모델만 펼쳐집니다. FAQ 제목은 두 줄이며, 첫 질문은 모바일 두 줄·PC 한 줄로 표시됩니다.

영상 목록은 BMW는 끼쟁이 채널의 공개 업로드 중 최근 최대 12편을 자동으로 가져옵니다. 공개 피드에는 Shorts나 라이브 영상도 포함될 수 있습니다. 삭제·비공개 전환은 다음 정상 동기화 때 반영됩니다. 목록 연결이 실패하면 저장된 목록과 채널 바로가기를 제공합니다. YouTube 계정의 재생목록을 만들거나 변경한 것은 아닙니다. 방문자가 재생을 시작하면 현재 영상 종료 후 다음 영상으로 이동하며 마지막 영상에서 멈춥니다. 재생 실패 시 다시 시도하거나 YouTube 원본 링크로 이동할 수 있습니다. 브라우저의 자동 재생 제한이 적용되면 플레이어 내부 재생 버튼을 누르면 됩니다.

재생 버튼 또는 영상 목록을 누르면 페이지 안에서 바로 재생합니다. 별도 동의 팝업은 없습니다. 외부 서비스 안내는 플레이어 아래와 푸터에 연결했습니다.

자동 갱신은 페이지 접속 시와 열려 있는 페이지에서 10분 간격으로 확인합니다. 숨겨진 탭과 영상을 선택했거나 목록에 키보드 초점이 있는 페이지에서는 목록을 교체하지 않습니다. Vercel은 정상 응답을 10분 동안 캐시하며, 만료 직후에는 최대 60초간 이전 응답을 제공하면서 갱신할 수 있습니다. YouTube 자체의 공개 피드 갱신 지연도 있으므로 업로드 후 정확히 10분 이내 반영을 보장하지 않습니다.

키가 설정되면 YouTube Data API의 업로드 재생목록을 우선 조회하고, 실패하면 공식 공개 피드를 확인합니다. API 키는 서버에서만 사용합니다. 키가 없으면 공개 피드 두 경로를 시도합니다. 둘 다 실패하면 새 목록이라고 표시하지 않으며 기존 재생 목록을 유지합니다. 피드에서 제공하지 않는 영상 길이는 임의로 표시하지 않습니다.

저장된 스냅샷을 바꿀 때만 `dist/videos.json`을 수정하고 `node scripts/render-videos.cjs`를 실행합니다. 새 업로드를 표시하기 위해 매번 이 파일을 수정하거나 재배포할 필요는 없습니다.

## SEO / AI 검색 준비

주요 내용은 JavaScript 실행 없이 HTML로 제공됩니다. `lang=ko`, 고유 제목·설명, canonical, Open Graph 제목·설명, 의미 있는 제목 구조, 이미지 대체 텍스트, Person·AutoDealer·WebSite·WebPage·FAQPage JSON-LD, robots.txt, sitemap.xml을 포함했습니다. JSON-LD의 FAQ는 보이는 본문과 동일합니다. `llms.txt`는 정보 확인을 돕는 보조 파일이며 검색 순위나 AI 인용을 보장하는 표준은 아닙니다.

공유 이미지와 Twitter 카드 정보도 포함합니다. 자체 25개 구현 항목은 수정 전 84/100에서 100/100으로 개선됐습니다. Lighthouse나 실제 공개 사이트 SEO 점수는 측정하지 않았습니다. 검사 범위·근거·공개 전 필요한 작업은 `REVIEW.md`에 명시했습니다.

현재 수정본의 대표 도메인은 `https://www.bmwgjbaek.com`입니다. 도메인을 변경하면 `update-seo.py`의 ORIGIN을 바꾼 뒤 `python3 update-seo.py`를 실행하세요. 비공개 또는 인증이 필요한 사이트는 검색엔진이 정상 수집할 수 없습니다. 공개 후 소유자 계정으로 Google Search Console과 네이버 서치어드바이저의 사이트 소유권 인증 및 사이트맵 제출이 필요합니다. 인증 토큰은 제공되지 않아 임의로 추가하지 않았습니다.

상위 노출은 경쟁도, 사이트 신뢰, 콘텐츠 품질과 축적, 운영 이력, 검색 플랫폼의 정책 등 영향을 받으므로 보장할 수 없습니다. FAQ 구조화 데이터가 검색결과의 FAQ 확장 표시를 보장하지도 않습니다.
